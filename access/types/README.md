# READI Access types

*Draft 2026.12-pre, proposed. Part of READI Access (https://readi.page/access). Text CC BY 4.0.*

Each type is the `type` of an `authorization_details` entry (RFC 9396), published at its own URL with the plain-language text an approval screen shows (RA-3.3).

| Type | Means |
|---|---|
| [`https://readi.page/access/types/booking`](./booking.md) | Make, change or cancel a booking at one place, on the terms shown. |
| [`https://readi.page/access/types/read`](./read.md) | See information at one site. Can’t make, change or cancel anything. |

More types (quote requests, appointment changes, payments) are an open question in flow 3.
