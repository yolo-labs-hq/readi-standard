# Security

Report security problems privately to **security@yololabs.ai**. Don’t open a public issue.

This covers this repository, [readi.page](https://readi.page) and the READI Access demo endpoints it serves. Include the affected URL or document, what you found, and how to reproduce it.

Problems in the text of the standard itself, such as a flow that would let an agent act without a person’s approval, are also welcome here before they go public.
